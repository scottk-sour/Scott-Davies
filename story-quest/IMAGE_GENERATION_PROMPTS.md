## How to Generate Images

### Option 1: ChatGPT with DALL-E 3
1. Go to ChatGPT (https://chat.openai.com)
2. Copy each prompt above
3. Paste and generate
4. Download as the specified filename

### Option 2: Midjourney
1. Go to Midjourney Discord
2. Use `/imagine` command
3. Paste prompt (prompts already include `--ar 16:9`)
4. Download and rename to specified filename

### Option 3: Other AI Tools
- Leonardo.ai
- Stable Diffusion
- Adobe Firefly
- Any AI image generator that supports detailed prompts

## After Generating Images

1. Save all images to `public/images/stories/safe-place/`
2. Run the update script to link images to the story
